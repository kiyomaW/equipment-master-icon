# Equipment Master

Equipment Master is a maintenance management system for construction equipment.

## Purpose

- Register new equipment
- Print QR labels
- Scan QR codes to open equipment pages
- Record maintenance history
- Upload maintenance photos
- View maintenance history

## Frontend

- GitHub Pages
- HTML
- CSS
- JavaScript

## Backend

- Google Apps Script

## Database

Google Sheets

Sheets:

- Equipment_Master
- Form_Responses
